# Security policy

This repository is a source directory with small maintenance scripts; it does not operate a service or store secrets.

## Reporting a vulnerability

Please use GitHub's **Report a vulnerability** feature for this repository when available. If it is unavailable, contact the repository maintainers privately through GitHub and avoid publishing exploit details until a fix or mitigation can be coordinated. Do not use the public issue tracker for sensitive reports.

Reports should include the affected file or workflow, impact, and a safe reproduction where possible. Do not send credentials, personal data, or live malicious payloads.

## Scope and response

The project can review vulnerabilities in its scripts, schema, and GitHub Actions. The directory links to independent third-party sites; their security and availability are outside this project's control. There is no service-level response-time commitment.
